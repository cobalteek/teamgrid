# TeamGrid

**TeamGrid** — веб-приложение для управления графиком смен сотрудников.

Система предназначена для компаний, где сотрудники работают по сменному графику. Она позволяет администраторам формировать расписание, а сотрудникам — удобно просматривать свои смены и отправлять заявки на изменение графика.

## Возможности

### Для сотрудников

- Просмотр личного графика смен.
- Просмотр расписания по дням.
- Удобная мобильная версия с лентой дней.
- Просмотр информации о своей смене.
- Отправка заявок на изменение графика.
- Отслеживание статуса отправленных заявок.

### Для администратора

- Просмотр графика сотрудников.
- Назначение смен сотрудникам.
- Создание и редактирование расписания.
- Изменение уже назначенных смен.
- Управление сотрудниками.
- Просмотр заявок на изменение графика.
- Подтверждение или отклонение заявок сотрудников.
- Централизованное управление расписанием команды.

## Основная концепция

TeamGrid разделяет работу с расписанием на две стороны:

```text
                    TeamGrid
                       │
             ┌─────────┴─────────┐
             │                   │
        Сотрудник            Администратор
             │                   │
       ┌─────┴─────┐       ┌─────┴──────────┐
       │           │       │                │
    График       Заявки   График         Управление
       │           │       │                │
   Просмотр    Изменение  Создание       Сотрудники
                            │             Заявки
                         Редактирование
```

Сотрудник не изменяет расписание напрямую. Вместо этого он отправляет заявку, которую рассматривает администратор.

Это позволяет сохранить единый источник актуального расписания и избежать случайных изменений.

## Интерфейс

Главный принцип интерфейса — **простота и ориентация на функциональность**.

### Desktop

На больших экранах расписание может отображаться в виде полноценной сетки:

- сотрудники;
- даты;
- назначенные смены;
- дополнительные состояния;
- действия администратора.

### Mobile

На мобильных устройствах расписание адаптируется под небольшой экран.

Основной формат — **лента дней**, позволяющая быстро переключаться между датами и просматривать назначенную смену.

## Роли

В системе предусмотрено разделение прав доступа.

### Employee

Обычный сотрудник:

- просмотр собственного расписания;
- просмотр информации о сменах;
- создание заявок;
- просмотр статуса заявок.

### Admin

Администратор:

- управление расписанием;
- управление сотрудниками;
- редактирование смен;
- обработка заявок;
- доступ к административной части приложения.

## Заявки на изменение графика

Одна из ключевых функций TeamGrid — система заявок.

Пример сценария:

```text
Сотрудник
    │
    │ Создаёт заявку
    ▼
┌───────────────┐
│    Заявка     │
│ на изменение  │
│    графика    │
└───────┬───────┘
        │
        ▼
   Администратор
        │
   ┌────┴────┐
   │         │
Одобрить   Отклонить
   │         │
   ▼         ▼
График     Без изменений
обновлён
```

Это позволяет сотрудникам самостоятельно инициировать изменения, сохраняя контроль расписания за администрацией.

## Цель проекта

TeamGrid решает простую практическую задачу — **сделать управление сменным графиком удобным как для сотрудников, так и для руководителей**.

Вместо таблиц, сообщений и ручного согласования в разных местах вся информация о расписании и изменениях находится в одном приложении.

## Основные принципы

- **Простота** — интерфейс не перегружен лишними элементами.
- **Удобство** — расписание должно быть понятно с первого взгляда.
- **Мобильность** — приложение удобно использовать со смартфона.
- **Контроль** — изменения графика проходят через администратора.
- **Централизация** — актуальное расписание хранится в одном месте.
