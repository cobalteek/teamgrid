## Что должно попасть на сайт

1. `01-policy.md` — политика обработки персональных данных и сведения о мерах защиты.
2. `02-consent.md` — отдельное согласие на обработку персональных данных.
3. `03-user-agreement.md` — пользовательские условия, если сервис предоставляется на договорной
