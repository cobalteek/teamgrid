## 2. Хостер и обработчики

По репозиторию подтверждены следующие технические зависимости:

- PostgreSQL — основная база данных приложения;
- GitHub Actions и `appleboy/ssh-action` — доставка кода на сервер по SSH;
- домен `cobalteek.tech` и HTTPS-продакшен — проверить фактического DNS/reverse-proxy и владельца
  сертификата.

GitHub Actions не должны получать выгрузки пользовательской базы. Если в CI/CD, логах, бэкапах или
мониторинге появляются персональные данные, соответствующий сервис добавляется в реестр отдельно.

Основной хостинг-провайдер: CloudCore, ООО «АйТи Аутсорсинг», ИНН 7602077973, ОГРН 1107602002221.
Юридический адрес провайдера: 150044, Ярославская область, г. Ярославль, ул. Полушкина Роща, д. 16,
к. 3. Этот адрес не является адресом базы данных оператора. По репозиторию также подтверждены GitHub
Actions и SSH-деплой. Нужно получить и сохранить:

- полное наименование, ИНН и договор;
- страну и полный адрес базы данных/ЦОДа;
- перечень услуг и доступов к данным;
- условия поручения обработки, конфиденциальности и уведомления об инцидентах;
- место и порядок хранения резервных копий, если провайдер их создаёт;
- перечень субподрядчиков и трансграничных потоков;
- порядок возврата и уничтожения данных после прекращения договора.

По текущему коду не обнаружены подключённые аналитика, Sentry, SMTP, OAuth или CAPTCHA. Это не
заменяет проверку серверных конфигураций, DNS, reverse proxy, резервного копирования и журналов.

Операторские резервные копии сейчас отдельно не ведутся и не заявляются. Возможные snapshots или
резервные копии провайдера нужно подтвердить по договору и панели управления. Публичный документ не
называет юридический адрес провайдера адресом ЦОДа и не делает окончательный вывод об отсутствии
трансграничной передачи без проверки договора и инфраструктуры.
